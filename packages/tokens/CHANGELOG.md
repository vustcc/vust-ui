## [0.1.0-alpha.1] - 2026-09-10

### Added

- 首次发布 `@vustcc/tokens` VDL 主题 Token。
- 提供浅色与深色主题的颜色、文字、边框、状态和背景变量。

- CSS 自定义属性统一使用 `--vdl-*` 前缀。
